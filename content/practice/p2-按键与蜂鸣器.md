# 实操二：按键开关与蜂鸣器

> 目标：掌握按键输入（数字输入）与蜂鸣器输出，理解上拉/下拉电阻。

## 一、准备材料

- 面包板、按键（微动开关）、蜂鸣器（有源）、LED、限流电阻
- 上拉/下拉电阻 10kΩ
- Arduino 板 + 杜邦线

## 二、按键的两种接法

**接法 A：上拉电阻（默认高电平）**
- 按键一端接 GND，另一端接数字输入口（如 D2）。
- 在输入口与 VCC 之间接 10kΩ 上拉电阻。
- 未按下时读 1，按下时读 0。

**接法 B：下拉电阻（默认低电平）**
- 按键一端接 VCC，另一端接输入口。
- 输入口与 GND 之间接 10kΩ 下拉电阻。
- 未按下时读 0，按下时读 1。

> 为什么接电阻：不接时输入口悬空，电平不稳定，会误触发。

## 三、蜂鸣器接线

- **有源蜂鸣器**：正极接数字输出口（如 D9，串一个限流电阻），负极接 GND。通电即响。
- **无源蜂鸣器**：需要输出特定频率方波（用 tone() 函数）才会发声。

## 四、示例逻辑（按下按键，蜂鸣器响）

```
按下按键 → 读到低电平(0) → 蜂鸣器通电发声
松开按键 → 读到高电平(1) → 蜂鸣器停止
```

对应代码结构：`if (按键按下) { 蜂鸣器响 } else { 蜂鸣器停 }`——**选择结构**。

## 五、测试

1. 按下按键，蜂鸣器响、LED 亮；松开停止。
2. 把上拉改下拉，观察逻辑反转（按下读到 1）。

## 六、易错点

- 忘记上拉/下拉电阻 → 引脚悬空抖动、误触发。
- 有源蜂鸣器接反 → 不响。
- 蜂鸣器直接接 5V 长时间可能过流，建议串限流电阻或经三极管驱动。
