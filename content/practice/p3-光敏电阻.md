# 实操三：光敏电阻——环境光线检测

> 目标：理解模拟量读取与分压电路，实现"光线暗时自动点亮 LED"。

## 一、准备材料

- 光敏电阻 × 1、固定电阻 10kΩ × 1
- LED × 1、限流电阻 220Ω
- Arduino 板、面包板、杜邦线

## 二、原理：分压电路

光敏电阻阻值随光照变化（光强→阻值小，光弱→阻值大）。把它与一个固定电阻**串联分压**，中间点的电压就会随光照变化。

```
VCC ── 光敏电阻 ──┬── 10kΩ ── GND
                 │
              A0（模拟输入）
```

中间点电压 = 随光照变化的模拟量，接入 Arduino 模拟口 A0。

## 三、读取模拟量

- `analogRead(A0)` 返回 0~1023 的数值（对应 0~5V）。
- 光线越暗，光敏阻值越大，A0 读数越大（取决于分压接法）。
- 记录亮/暗两种环境下的读数，确定**阈值**。

## 四、实现逻辑（天黑自动开灯）

```
读 A0 数值
if (A0 > 阈值)  →  点亮 LED（说明光线暗）
else            →  熄灭 LED
```

## 五、测试与标定

1. 用手遮住光敏电阻，观察 A0 读数变大。
2. 设定阈值（如亮时 300、暗时 800，阈值取中间 500）。
3. 遮光时 LED 自动亮起，见光熄灭。

## 六、易错点

- 分压电阻选错（太小则变化不明显）。
- 阈值取得太极端 → 频繁闪烁（可加回差/延时防抖）。
- 接错分压顺序 → 逻辑相反（亮灯变灭灯），调换光敏与电阻位置即可。
