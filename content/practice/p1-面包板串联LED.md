# 实操一：面包板搭一串 LED 串联电路

> 目标：认识面包板与元器件，完成 LED 串联电路，理解限流电阻与正负极。

## 一、准备材料

- 面包板 × 1
- LED × 2~3 个
- 限流电阻 220Ω~1kΩ × 2~3 个
- 杜邦线若干
- 电池盒 / Arduino 5V 供电

## 二、认识面包板

- **两侧电源轨**：上下各两条长横排，通常红色标正极（+）、蓝色标负极（−），整条内部连通。
- **中间插孔**：竖列每 5 个孔内部连通，中间有隔离槽，左右两侧互不相通。
- 插元件时引脚要插到位，避免接触不良。

## 三、电路连接步骤

1. **固定 LED**：LED 长脚为正极、短脚为负极，插到面包板中间区域。
2. **串联连接**：第一个 LED 的负极接到第二个 LED 的正极，形成串联。
3. **接限流电阻**：在串联回路中串入一个限流电阻（220Ω~1kΩ），限制电流保护 LED。
4. **接电源**：电源正极 → 电阻 → LED1 → LED2 → 电源负极，形成一个闭合回路。
5. **检查**：确认每个 LED 方向正确（长脚接高电位一侧）、无短路。

## 四、测试与现象

- 通电后所有 LED 应同时点亮（串联：一个断开全灭）。
- 拔掉一个 LED，其余全灭 → 验证串联特点。
- 换更大的限流电阻 → LED 变暗 → 理解电阻限流。

## 五、易错点与规范

- LED 正负极接反不亮。
- 忘接限流电阻，LED 可能烧毁。
- 短路：电源正负极直接连通，会发烫甚至损坏电池/板子，务必先检查再通电。
- 连线整齐、不交叉、颜色区分（红正黑负）——这是考核中的「电路规范性」。

## 六、拓展

- 改成**并联**接法：每个 LED 各串一个限流电阻后再并到电源上，观察「一个灭不影响其他」。
