# 实操四：超声波避障小车

> 目标：掌握超声波测距 + 机器人避障控制逻辑（自招实操高频考点）。

## 一、准备材料

- 小车底盘（两个直流电机 + 轮子，或舵机/电机驱动板）
- 超声波传感器 HC-SR04 × 1
- 电机驱动模块（如 L298N / 电机驱动板）
- Arduino 板、电池盒、杜邦线

## 二、超声波接线（HC-SR04）

| 引脚 | 接 Arduino |
|---|---|
| VCC | 5V |
| GND | GND |
| TRIG | 数字输出口（如 D9） |
| ECHO | 数字输入口（如 D10） |

**测距原理**：TRIG 给一个 10µs 高电平触发 → 模块发超声波 → 收到回波 ECHO 输出高电平，高电平持续时间 = 声波往返时间。

```
距离 = 声速 × 时间 ÷ 2
声速 ≈ 340m/s = 0.034cm/µs
```

## 三、避障控制逻辑

```
loop:
  读距离 distance
  if (distance < 10cm):
      停车 → 后退一点 → 转向（左或右）
  else:
      前进
```

> 阈值（10cm）是「制动距离」：距离小于阈值就制动/转向，大于阈值就前进。

## 四、电机控制

- 用电机驱动模块控制两个直流电机正反转。
- 前进：两轮同向正转；后退：同向反转。
- 左转：右轮转、左轮停或反转（差速转向）。

## 五、测试步骤

1. 先单独测超声波：串口打印距离，用手靠近验证读数。
2. 再测电机：分别让小车前进/后退/左转/右转。
3. 组合：小车前进，遇到障碍（<10cm）自动后退转向绕开。

## 六、易错点

- ECHO 必须接数字输入口，TRIG 接数字输出口。
- 忘记除以 2（声波是往返）。
- 阈值设太小 → 撞上才反应；太大 → 太早转向。
- 电机正反转接反 → 转向方向相反，单独标定每个电机。
