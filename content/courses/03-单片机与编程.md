# 单片机与编程

> 硬件项目的大脑是单片机。深圳自招笔试考**编程逻辑、流程图、进制**，很多学生校内没接触过 Arduino，是拉分项。

## 1. 常见控制板

- **Arduino UNO R3**：最常用的开源控制板，基于 ATmega328P，5V 工作电压，有数字口 D0~D13、模拟口 A0~A5。适合入门和竞赛。
- **ESP32**：带 WiFi/蓝牙，3.3V，适合物联网项目，性能更强。
- **扩展板（Shield）**：插在主板上扩展传感器接口、电机驱动等。

## 2. 编程软件

- **Mixly（米思齐）**：国产**图形化编程**，拖拽积木块，适合入门（三级常考）。
- **Arduino IDE**：写 **C/C++ 代码**，`setup()` + `loop()` 结构（四级起）。

> `setup()` 只运行一次（初始化），`loop()` 反复循环执行（主逻辑）。

## 3. 程序三大基本结构

1. **顺序结构**：从上到下依次执行。
2. **选择（条件分支）结构**：`if / else`，满足条件走一路，不满足走另一路。
3. **循环结构**：`for`、`while`，重复执行一段代码。

> 经典题："机器人行进指令：直行→左转→直行→右转"体现的是**顺序结构**；"距障碍 10cm 则制动，否则前进"体现的是**选择结构**。

## 4. 变量、函数与运算符

- **变量**：存储数据的容器，如 `int speed = 100;`（整型）、`float distance;`（小数）、`bool flag;`（真假）。
- **函数**：封装一段可复用的代码。Arduino 中 `setup()`、`loop()` 是函数；也可自定义函数（如 `void moveForward(){}`）。
- **算术运算**：`+ - * / %`（取余）。
- **比较运算**：`> < >= <= == !=`。
- **逻辑运算**：`&&`（与，都真才真）、`||`（或，有真即真）、`!`（非，取反）。

## 5. 流程图

- **起止框**：圆角矩形（开始/结束）。
- **处理框**：矩形（执行动作）。
- **判断框**：菱形（条件判断，两分支）。
- **流程线**：箭头表示走向。

> 会读、会画流程图是考核点：把"传感器判断 → 电机动作"画成流程图。

## 6. 进制转换（四级以上）

- **二进制**：只有 0 和 1，逢二进一。`1010`(二) = `10`(十)。
- **十进制**：日常计数。
- **十六进制**：0~9 与 A~F，逢十六进一。常用于颜色、地址。
- 换算方法：二进制转十进制用"按权展开相加"；十进制转二进制用"除 2 取余，倒序排列"。

## 7. 进阶：中断、串口与总线

- **中断（interrupt）**：正在执行时被高优先级事件打断，处理完再返回。适合按键、传感器触发（五级）。
- **串口通信 UART**：两条线 TX（发）、RX（收），用于与电脑/模块通信，波特率要一致。
- **I²C 总线**：两根线 SDA（数据）、SCL（时钟），可挂多个设备（如显示屏、传感器）。
- **SPI 总线**：四线高速通信，常用于屏幕、存储。
- **PWM（脉宽调制）**：通过占空比控制"平均电压"，实现调光、调速（舵机角度、电机转速靠它）。

## 8. 引脚模式与常用函数（Arduino 方向重点）

Arduino 控制硬件，核心是「先设置引脚模式，再读写」：

- **pinMode(引脚, 模式)**：设置引脚为 INPUT（输入）或 OUTPUT（输出），使用引脚前必须先调用。
- **digitalWrite(引脚, HIGH/LOW)**：数字输出，写高/低电平（点亮/熄灭 LED）。
- **digitalRead(引脚)**：数字输入，读取引脚是高(HIGH)还是低(LOW)（读按键）。
- **analogRead(引脚)**：模拟输入，读取 A0~A5 的模拟电压，返回 **0~1023** 的整数。
- **analogWrite(引脚, 0~255)**：用 **PWM** 实现"模拟输出"（调光、调速）。

> 易错点：模拟输入用 analogRead（接 A 口，返回 0~1023）；模拟输出其实是用 PWM 的 analogWrite（接带 ~ 的数字口，参数 0~255），二者不要混淆。

## 9. 控制大功率器件：继电器与 H 桥

- **继电器**：小电流控制大电流，驱动 220V 大功率负载，实现弱电控强电、电气隔离。
- **H 桥**：控制直流电机**正反转**（前进 / 后退）。

## 10. Python 基础（对应信息技术考点）

深大附中等校信息技术自招会考 Python/C 的函数分析。机考不要求写代码，但要求**能读懂**函数、循环、判断。

- **Python 是什么**：一门简单易读的编程语言，也是人工智能、数据分析的常用语言。
- **print()**：输出信息，如 `print("hello")` 会显示 hello。
- **变量**：存数据的容器，如 `x = 5`、`name = "小明"`。
- **数据类型**：整数 int、小数 float、字符串 str、真假 bool。
- **if / elif / else**：条件判断，`if 条件: 做A; else: 做B`。
- **for / while**：循环。`for i in range(3):` 重复 3 次；`while 条件:` 满足条件就重复。
- **def 函数**：封装一段可复用代码，例如：

```python
def light_control(brightness):
    if brightness < 50:   # 亮度小于 50
        print("开灯")
    else:
        print("关灯")
```

> 记忆要点：能看懂「函数名(参数)」、`if` 判断、`for` 循环在做什么即可，不用自己写代码。

## 常见考题方向

1. 判断代码片段属于哪种程序结构、输出结果。
2. 运算符优先级、逻辑运算真值（与或非）。
3. 进制换算。
4. 用图形化编程/伪代码描述一个任务（如循迹、避障、流水灯）。
