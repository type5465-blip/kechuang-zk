# 数理基础

> 深圳创新高级中学硬件方向笔试：**数学 40 分 + 物理 30 分 + 逻辑/工程思维 30 分**。数理是底层支撑，本模块梳理高频考点。

## 1. 力学基础

- **力**：物体对物体的作用，单位牛顿（N）。力的三要素：大小、方向、作用点。
- **重力**：G = mg，方向竖直向下。
- **压强**：p = F / S，单位帕斯卡（Pa）。受力面积越小压强越大（刀口锋利、图钉尖）。
- **浮力**：阿基米德原理 F浮 = ρ液·g·V排；物体漂浮时浮力 = 重力。
- **杠杆平衡**：F1·L1 = F2·L2（动力 × 动力臂 = 阻力 × 阻力臂）。
- **功与功率**：W = F·s（功），P = W / t（功率）。

## 2. 电学基础（与电路模块联动）

- **欧姆定律**：I = U / R。
- **串联**：R总 = R1 + R2；电流处处相等，总电压 = 各电压之和。
- **并联**：1/R总 = 1/R1 + 1/R2；各支路电压相等，干路电流 = 各支路之和。
- **电功率**：P = U·I = I²R = U²/R。
- **电功/电能**：W = P·t = U·I·t。

**典型计算**：两电阻 R1、R2 串联接在 12V 电源上，求电流、各电阻分压；并联求总电阻、各支路电流。

## 3. 几何与图形

- **三角形**：内角和 180°；勾股定理 a² + b² = c²；三角形具有稳定性（桥梁、支架常用）。
- **圆**：周长 C = 2πr，面积 S = πr²。
- **体积/面积**：长方体 V = abc，圆柱 V = πr²h。
- **结构稳定性**：三角形最稳定；四边形可变形（加对角线固定）。

## 4. 逻辑与工程思维（30 分重点）

笔试中的"逻辑与工程思维 / 计算思维"通常考查：

- **逻辑推理**：给条件推结论、排列组合、真假判断。
- **流程与算法**：把任务拆成步骤，画流程图，写出判断条件（如循迹、避障）。
- **机械结构分析**：选齿轮比、判断受力、稳定性分析。
- **创新设计题**：给定目标（如"做一个自动浇花装置"），描述方案、所需传感器与执行器、工作流程。

**答题模板（方案设计题）**：
1. 目标与需求（要实现什么功能）。
2. 选用元件（传感器测什么、执行器做什么）。
3. 工作流程（输入 → 判断 → 输出，可用流程图）。
4. 关键阈值/参数（如"土壤湿度 < 某值 → 启动水泵"）。

## 5. 力学进阶（深实验 / 深高物理高频考点）

- **加速度 a**：描述速度变化快慢，单位 m/s²。
- **牛顿第二定律**：F = ma（力 = 质量 × 加速度），力越大或质量越小，加速度越大。
- **圆周运动**：物体沿圆周运动，速度方向**沿切线不断改变**，需要**向心力**指向圆心（如卫星绕地、汽车过弯）。
- **机械能**：动能 + 势能（重力势能、弹性势能）；忽略阻力时**机械能守恒**，动能和势能互相转化、总和不变。

## 6. 电磁初步（深实验物理考点）

- **电场**：电荷周围存在电场，同种电荷相斥、异种电荷相吸。
- **电磁感应**：**闭合电路的一部分导体做切割磁感线运动**时，产生**感应电流**（发电机原理）。
- **常见应用**：发电机（机械能→电能）、电动机（电能→机械能）、电磁铁。

## 常见考题方向

1. 欧姆定律、串并联电阻与电功率计算。
2. 压强、浮力、杠杆平衡的应用判断。
3. 三角形稳定性、几何计算。
4. 工程方案设计题（自动控制装置、循迹/避障任务）。
