# 数理基础

> 深圳创新高级中学硬件方向笔试：**数学 40 分 + 物理 30 分 + 逻辑/工程思维 30 分**。本模块聚焦初中数学与物理基础（逻辑思维部分见「逻辑与工程思维」模块）。

## 1. 力学基础

- **力**：物体对物体的作用，单位牛顿（N）。力的三要素：大小、方向、作用点。
- **重力**：G = mg，方向竖直向下。
- **压强**：p = F / S，单位帕斯卡（Pa）。受力面积越小压强越大（刀口锋利、图钉尖）。
- **浮力**：阿基米德原理 F浮 = ρ液·g·V排；物体漂浮时浮力 = 重力。
- **功与功率**：W = F·s（功），P = W / t（功率）。
- **机械能**：动能（运动的物体具有）+ 势能（重力势能、弹性势能）；动能和势能可以**相互转化**，忽略阻力时机械能保持不变。

## 2. 简单机械

- **杠杆平衡**：动力 × 动力臂 = 阻力 × 阻力臂（F1·L1 = F2·L2）。
- **滑轮**：定滑轮改变力的方向（不省力）；动滑轮省一半力；滑轮组既省力又可改变方向。

## 3. 电学基础（与电路模块联动）

- **欧姆定律**：I = U / R。
- **串联**：R总 = R1 + R2；电流处处相等，总电压 = 各电压之和。
- **并联**：1/R总 = 1/R1 + 1/R2；各支路电压相等，干路电流 = 各支路之和。
- **电功率**：P = U·I = I²R = U²/R。
- **电功 / 电能**：W = P·t = U·I·t。

**典型计算**：两电阻 R1、R2 串联接在 12V 电源上，求电流、各电阻分压；并联求总电阻、各支路电流。

## 4. 电与磁（初中 9 年级）

- **磁体**：同名磁极相斥，异名磁极相吸；磁体周围有磁场。
- **电磁铁**：通电的螺线管 + 铁芯，磁性强弱与电流大小、线圈匝数有关；通断电可控制其有无磁性。
- **电磁感应**：**闭合电路的一部分导体做切割磁感线运动**时，产生**感应电流**（发电机原理）。
- **电动机**：通电线圈在磁场中受力转动，把电能转化为机械能。
- **常见应用**：发电机（机械能→电能）、电动机（电能→机械能）、电磁铁（电磁继电器、起重机）。

## 5. 几何与图形

- **三角形**：内角和 180°；勾股定理 a² + b² = c²；三角形具有稳定性（桥梁、支架常用）。
- **圆**：周长 C = 2πr，面积 S = πr²。
- **体积 / 面积**：长方体 V = abc，圆柱 V = πr²h。
- **结构稳定性**：三角形最稳定；四边形可变形（加对角线固定）。

## 常见考题方向

1. 欧姆定律、串并联电阻与电功率计算。
2. 压强、浮力、杠杆平衡、滑轮的应用判断。
3. 电磁感应、发电机、电动机、电磁铁的原理判断。
4. 三角形稳定性、几何计算。
