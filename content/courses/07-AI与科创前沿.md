# AI 与科创前沿

> 深圳科创机考近年加入「AI 应用理解」，面试考「科创常识」。本模块不要求写 AI 代码，考的是「能不能理解 AI 是什么、怎么用」。

> **📌 本模块考点速览**
> 先掌握：AI 是什么、机器学习「从数据中学出规律」与普通程序「写死规则」的区别。
> 重点看：「传感 + AI」的感知→判断→执行三步，以及人脸识别、语音助手等常见 AI 应用的判断。
> 易错点：把机器学习误当成"人工写死的程序"；说不出场景里感知、判断、执行各用什么。

## 1. 人工智能（AI）基础

- **人工智能（AI）**：让机器模拟人的智能——识别图像、理解语音、做出决策。
- AI 能做什么：看图识物、听懂语音、下棋、翻译、推荐。
- AI 的局限：缺乏真正的理解与常识，数据有偏见时结果也会偏，需人工把关。

## 2. 机器学习入门

- **机器学习**：让机器**从数据中「学」出规律**，而不是人工写死规则。
- **训练 vs 识别**：先用大量标注数据「训练」模型，再用新数据「识别 / 预测」。
- 简单例子：给机器看几千张猫和狗的图片，它自己总结出区分特征，之后见到新图片能判断是猫还是狗。

## 3. 常见 AI 应用

- **人脸识别**：摄像头采集人脸 → AI 比对特征 → 开门 / 打卡。
- **语音助手**：麦克风采集语音 → 语音识别转文字 → 理解意图 → 执行。
- **图像分类**：识别照片里的物体、医学影像判断病情。
- **智能推荐**：根据你的浏览 / 购物记录推荐内容。
- **自动驾驶**：摄像头 / 雷达感知 → AI 决策 → 控制车辆。

## 4. 传感器 + AI（感知 → 判断 → 执行）

硬件科创项目常用「传感 + AI」组合：

1. **感知**：传感器采集数据（图像、声音、温度、距离）。
2. **判断**：AI 分析数据做出决定。
3. **执行**：执行器（电机、舵机、蜂鸣器）执行动作。

> 例：智能垃圾分类——摄像头（感知）→ AI 识别垃圾种类（判断）→ 舵机转到对应桶（执行）。

## 5. 科创前沿科技

- **无人机**：多旋翼飞行器，靠飞控 + 传感器实现自主飞行、航拍、测绘。
- **机器人**：工业机器人、服务机器人、竞赛机器人（循迹、避障）。
- **物联网（IoT）**：把设备联网，远程采集数据、控制（如智能家居）。
- **3D 打印**：把数字模型逐层打印成实物，用于制作机器人零件。

## 6. 科创常识（面试常问）

- **科技特长生**：通过科创类自主招生进入高中，靠科创成果 / 竞赛奖项 + 校考。
- **白名单赛事**：教育部公布的全国性竞赛名单（如青少年科技创新大赛、青少年无人机大赛、宋庆龄少年儿童发明奖等），奖项是自招报名的重要依据。
- **发明创造**：发现生活中的问题 → 提出方案 → 动手实现 → 迭代改进。

## 7. 科创项目方法论

做一个科创项目的一般流程（面试答辩也按这个讲）：

1. **选题**：从生活问题出发，小而具体。
2. **方案设计**：选传感器 / 执行器、画流程图。
3. **动手实现**：搭硬件、写程序、反复调试。
4. **迭代改进**：测试发现问题，改进后再测。
5. **总结展示**：记录过程（设计书 / 日志 / 照片 / 视频），准备答辩。

## 常见考题方向

1. AI 是什么、机器学习和普通程序的区别。
2. 判断某功能属于哪种 AI 应用（人脸识别 / 语音 / 推荐）。
3. 「传感 + AI」组合：给场景说出感知、判断、执行各用什么。
4. 科创常识：白名单赛事、科技特长生、科创项目流程。

## 当堂自测

**1.（单选）机器学习与普通程序最本质的区别是？**
A. 机器学习运行更快　B. 机器学习从数据中「学」出规律，普通程序靠人工写死规则　C. 机器学习不需要电脑　D. 普通程序必须联网
- 答案与解析：选 B。机器学习先用大量标注数据「训练」模型，再对新数据识别 / 预测；普通程序则是人把规则一条条写出来。A、C、D 都不正确。

**2.（填空）「智能垃圾分类」中，摄像头采集图像属于____，AI 识别垃圾种类属于____，舵机转到对应桶属于____。**
- 答案与解析：感知、判断、执行。对应「传感 + AI」三步：传感器感知 → AI 判断 → 执行器执行动作。

- 答案与解析：正确。白名单赛事由教育部公布，如青少年科技创新大赛、青少年无人机大赛、宋庆龄少年儿童发明奖等，奖项是科创类自招报名的重要依据。
