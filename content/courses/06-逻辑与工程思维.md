# 逻辑与工程思维

> 深圳科创自招笔试有约 30 分考「逻辑与工程思维 / 计算思维」，深实验还有「数学逻辑推理」。本模块把散落的逻辑推理和方案设计题系统化。

## 1. 逻辑推理基础

- **条件推理（若…则…）**：由「如果 A 则 B」和「A 成立」推出「B 成立」。
- **真假判断**：给几句话，其中只有一句是真（或假），逐一假设、排除矛盾。
- **分类与枚举**：把情况按类别列出，做到不重不漏。

> 解题法宝：遇到逻辑题先**画表格或列举**，不要凭感觉猜。

## 2. 找规律与排列组合

- **数列找规律**：观察相邻项的差、比、乘方等规律，推出下一项。
- **排列**：n 个不同物体排成一列有 n! 种方法（n! = n × (n-1) × … × 1）。
- **组合 / 计数**：从 n 个中选 m 个，注意是否考虑顺序。

## 3. 流程与算法思维

- 把一件复杂任务**拆成按顺序执行的小步骤**。
- 用**流程图**表示：起止框（圆角矩形）→ 处理框（矩形）→ 判断框（菱形）→ 流程线（箭头）。
- 关键是把「判断条件」写清楚：例如「距离 < 10cm → 停车，否则前进」。

## 4. 工程方案设计题（重点）

笔试和面试常见的开放题：「设计一个自动 XX 装置」。答题四步：

1. **目标与需求**：要实现什么功能。
2. **选用元件**：用什么传感器测、什么执行器做。
3. **工作流程**：输入 → 判断 → 输出（可画流程图）。
4. **关键阈值 / 参数**：如「土壤湿度 < 某值 → 启动水泵」。

**典型例子**：

- 自动浇花：土壤湿度传感器 + 水泵（湿度低 → 浇水）。
- 自动路灯：光敏电阻 + LED/灯（天黑 → 亮灯）。
- 循迹小车：灰度传感器 + 电机（偏左 → 右转）。
- 避障小车：超声波 + 电机（距障碍 < 10cm → 转向）。

## 常见考题方向

1. 真假话推理、条件推理。
2. 数列 / 图形找规律。
3. 把任务画成流程图、写判断条件。
4. 给定目标写工程方案（选传感器/执行器 + 流程 + 阈值）。
