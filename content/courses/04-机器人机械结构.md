# 机器人机械结构

> 机械结构决定机器人"怎么动"。自招笔试考**齿轮比、传动、简单机械**，实操考**搭建与稳定性**。

> **📌 本模块考点速览**
> 先掌握：先把「齿轮比 = 从动齿数 ÷ 主动齿数」和"小齿轮带大齿轮减速省力、大带小加速省力"这两个基础记牢。
> 重点看：判断齿轮、链、带传动的转动方向和转速快慢（谁快、谁省力），这是笔试最常考的计算。
> 易错点：容易把齿轮比算反、把齿轮啮合"转向相反"和链/带传动"转向相同"记混，也别忘了"重心低、支撑面大才稳"。

## 1. 重心与重力

- **重力**：物体受到地球吸引的力，方向竖直向下。
- **重心**：重力作用集中的点。**重心越低、支撑面越大 → 越稳定**。
- 搭建原则：把重的元件放低、把底盘做大，机器人就不容易倒。

## 2. 六种简单机械

| 简单机械 | 例子 | 作用 |
|---|---|---|
| 杠杆 | 撬棍、剪刀 | 省力或省距离 |
| 轮轴 | 门把手、方向盘 | 省力 |
| 滑轮 | 升旗、起重机 | 改变力的方向/省力 |
| 斜面 | 斜坡、螺丝 | 省力 |
| 楔 | 斧头、钉子 | 劈开/固定 |
| 螺旋 | 螺丝、螺旋桨 | 旋转转化为直线运动 |

> 杠杆平衡：动力 × 动力臂 = 阻力 × 阻力臂（F1·L1 = F2·L2）。

## 3. 齿轮与齿轮比

- **齿轮传动**：两个齿轮啮合，**转动方向相反**（加惰轮可同向）。
- **齿轮比** = 从动齿轮齿数 ÷ 主动齿轮齿数。
  - 小齿轮带大齿轮 → **减速、增大力矩**（省力，速度慢）。
  - 大齿轮带小齿轮 → **加速、减小力矩**（速度快，力气小）。
- 齿数比决定转速比：齿轮比 3:1 表示主动轮转 3 圈从动轮转 1 圈。

## 4. 链传动与带传动

- **链传动**：链条 + 链轮，不打滑、传动比准确（如自行车）。
- **带传动**：皮带 + 皮带轮，可能打滑、有过载保护作用。
- 两者都可**远距离传动**，且两轮**转动方向相同**（与齿轮啮合不同）。

## 5. 凸轮、连杆、棘轮、曲柄

- **凸轮**：把旋转运动变成有规律的往复/间歇运动。
- **连杆**：连接转动与往复运动的杆件。
- **曲柄**：绕轴旋转、带动连杆（如发动机活塞）。
- **棘轮**：单向转动、防止倒转（如扳手、卷扬机）。

## 6. 电机与舵机

- **直流电机**：通电就连续旋转，转速快、扭矩小，常配**减速箱**增大扭矩；通过 PWM 调速、H 桥改变转向。
- **伺服电机（舵机）**：能转到**指定角度**（如 0°~180°），用 PWM 信号控制角度，适合机械臂、转向。
- **步进电机**：按固定角度一步步转，定位精确。

## 7. 开环控制与闭环控制

- **开环控制**：输入 → 执行，**不检测结果**、不反馈（如普通定时风扇）。
- **闭环控制（反馈控制）**：检测输出结果，与目标比较后调整（如空调根据温度自动启停、机器人循迹实时纠偏）。
- **自律型（反馈型）机器人**：能根据传感器反馈自主调整动作，如自动避障、循迹。

## 8. 底盘与运动

- **底盘**：常见**轮式**（差速转向：左右轮转速不同即转向）、**履带式**（越野越障强）。
- **运动**：电机可完成旋转、往复、摇摆等动作（通过连杆/凸轮等机构）。

## 9. 无人机（多旋翼）基础

深圳科创方向明确包含**无人机**，常见考点：

- **四旋翼**：四个电机 + 四个螺旋桨，通过调节各旋翼转速实现上升、下降、前后左右移动和转向。
- **升力原理**：旋翼转动向下推空气，空气反作用力向上推机身，升力大于重力时上升。
- **桨叶**：旋翼的桨叶相当于旋转的"斜面/螺旋"，把旋转运动转化为推力。
- **飞控**：无人机的"大脑"，通过陀螺仪等传感器感知姿态，自动调节各电机转速保持平衡（**闭环控制**）。
- 常见传感器：**陀螺仪 / 加速度计**（姿态）、**气压计**（高度）、**GPS**（定位）、**超声波**（低空避障）。

## 常见考题方向

1. 齿轮比、转速计算（谁转得快、谁省力）。
2. 判断传动方式、转动方向。
3. 稳定结构（重心低、支撑面大）。
4. 给一个任务（过障碍、爬坡、循迹）设计传动/底盘方案。

## 当堂自测

**1.（填空）小齿轮（12 齿）带动大齿轮（36 齿）时，从动轮（大齿轮）的转速变____，力矩变____。**
- 答案与解析：慢、大。齿轮比 = 从动齿数 ÷ 主动齿数 = 36 ÷ 12 = 3:1，属于"小齿轮带大齿轮 → 减速、增大力矩"，所以速度慢、力气（力矩）大。

**2.（判断）链传动中，两个链轮的转动方向相反。（ ）**
- 答案与解析：错误。链传动（和带传动一样）两轮转动方向相同；转动方向相反的是齿轮啮合传动。

**3.（填空）想让机器人爬坡、过障碍时不易翻倒，应让重心尽量____，支撑面尽量____。**
- 答案与解析：低、大。重心越低、支撑面越大，机器人越稳定，越不容易倒。
