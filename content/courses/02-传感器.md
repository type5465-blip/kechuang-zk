# 传感器

> 传感器是机器人、无人机感知外界的"眼睛和皮肤"。自招笔试常考**传感器选型与信号类型**，实操常考**循迹、避障**。

## 1. 传感器的信号类型

按输出信号分三类：

- **数字信号传感器**：输出 0 或 1。如**灰度传感器（循迹模块）**、**接近开关**、**触碰传感器**。
- **模拟信号传感器**：输出连续变化的电压。如**光敏电阻**、**光线强度传感器**。
- **数字脉冲信号传感器**：输出一串脉冲。如**超声波测距传感器**、**红外遥控接收头**。

> 记忆：能"测距离、传数据"的常是脉冲；只能"有/无"判断的常是数字；能"测强弱/大小"的常是模拟。

## 2. 灰度传感器（循迹模块）

- **原理**：利用黑线吸收光、白底反射光的差异，通过红外发射/接收判断黑白。检测到**黑色**输出一种电平，检测到**白色/浅色**输出另一种。
- **用途**：机器人**循迹**（沿黑线行走）。
- **典型逻辑**：左传感器遇到黑线 → 左转；否则直行。（"遇黑线左转，否则直行"）

## 3. 超声波测距传感器

- **原理**：发射超声波，遇到障碍物反射回来，根据**时间差**计算距离。
- **信号**：输出**数字脉冲**（脉冲宽度与距离成正比）。
- **典型模块**：HC-SR04（TRIG 触发、ECHO 回波）。
- **用途**：避障、测距。如"距障碍 10cm 处制动"。

## 4. 红外传感器

- **红外发射/接收**：发射红外线，检测是否有物体反射回来，用于**近距避障/循迹**。
- **红外遥控接收头**：接收遥控器信号，输出**数字脉冲**，用于遥控。

## 5. 光敏电阻与光线传感器

- **光敏电阻**：光照越强、阻值越小，属**模拟信号**。通过分压电路读取亮度。
- **应用**：环境光线检测、自动开灯、太阳能寻光。

## 6. 触碰传感器与接近开关

- **触碰传感器**：相当于一个按钮/微动开关，碰到物体输出数字量。
- **接近开关**：无需接触即可检测物体靠近，输出数字量。

## 7. 机器人避障与循迹逻辑（重点）

**避障**：
1. 超声波测距，读距离值。
2. 判断 `距离 < 阈值`（如 10cm）？
3. 是 → 停车/转向/后退；否 → 继续前进。

**循迹**：
1. 读灰度传感器。
2. 若左传感器在线上 → 左转。
3. 若右传感器在线上 → 右转。
4. 都在线上/都不在线上 → 直行/微调。

> 考核要点：能把"传感器读到的值"与"机器人该做什么动作"对应起来，写出判断逻辑。

## 8. 温湿度与温度传感器

- **DHT11**：数字式温湿度传感器，一条数据线即可读出**温度和湿度**，输出数字信号。
- **温度传感器（热敏电阻 NTC）**：温度升高阻值减小，输出**模拟量**，配合分压电路测温。
- **压力/重量传感器**：检测压力或重量，用于称重、碰撞力度检测。

## 9. 显示与执行类模块

- **点阵模块（LED 点阵）**：如 8×8 点阵，用于显示文字、图形、表情。
- **液晶显示屏（LCD / OLED）**：显示更多信息，通过 I²C 等总线控制。
- **蜂鸣器**：声音提示（执行器）。

## 10. 传感器选型速查表（重点背）

| 想检测什么 | 选什么传感器 | 信号类型 |
|---|---|---|
| 距离 / 避障 | 超声波 | 数字脉冲 |
| 循迹黑白线 | 灰度（红外） | 数字 |
| 光线强弱 | 光敏电阻 | 模拟 |
| 温度 / 湿度 | DHT11 / 热敏电阻 | 数字 / 模拟 |
| 声音 | 麦克风 / 声音传感器 | 模拟 / 数字 |
| 碰撞 / 接触 | 触碰开关 | 数字 |
| 物体靠近 | 接近开关 | 数字 |
| 压力 / 重量 | 压力传感器 | 模拟 |

## 常见考题方向

1. 给场景选传感器（测距选超声波、循迹选灰度、测光选光敏）。
2. 判断传感器输出信号类型（数字/模拟/脉冲）。
3. 写出避障或循迹的阈值判断逻辑。
4. "机器人要在距障碍 10cm 处停下，传感器逻辑应为大于还是小于阈值？"
